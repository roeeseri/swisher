# Pilot results — 2026-10-20

19 source clips were processed locally. Baseline: 190 shot proposals and 1 release proposal. Updated experimental pipeline: 207 shot proposals and 81 release proposals. These are unverified automatic proposals, not confirmed shots or makes.

Provisional candidate-guided visual reference: development clip 7/10 release intervals matched; two held-out clips 6/18 matched versus 1/18 baseline. This is not exhaustive independent ground truth or a population accuracy estimate. No makes/misses or coaching recommendations have been validated.

Raw videos, overlays, player images, pose traces, detection traces and individual measurements remain in the local artifacts directory and are excluded from Git. The scripts can regenerate the review dashboard locally. The consent form is included separately; signed forms must remain private.
