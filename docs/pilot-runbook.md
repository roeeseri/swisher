# Pilot Session Runbook

## ציוד

- טלפון עם מצלמה אחורית ו־1080p/60fps.
- חצובה יציבה.
- סוללה ואחסון פנוי.
- טופס הסכמה, ובקטינים גם אישור אפוטרופוס.

## מיקום המצלמה

- זווית צד־אלכסון של 30–60 מעלות.
- כל הגוף, הכדור והסל בפריים בכל רגע.
- ללא זום דיגיטלי וללא תזוזת מצלמה במהלך הסט.
- צלם שלוש זריקות בדיקה והעלה אותן לפני הסשן הגדול.

## מבנה הסשן הראשון

1. 20 זריקות Baseline ללא תיקון.
2. המאמן בוחר בעיה אחת, מתעד ראיה ונותן דגש אחד.
3. 5–10 דקות של תרגיל ממוקד.
4. 20 זריקות Post באותו מקום ובתנאים דומים.

## סדר העבודה במערכת

1. פתח Swisher ובחר Session Studio.
2. צור מזהי `session`, `player` ו־`coach` אנונימיים.
3. אשר שקיימת הסכמה מתועדת והעלה את הסרטון הרציף.
4. סמן 3 זריקות ראשונות בלבד ובדוק שהתהליך נוח.
5. עבור ל־Session Analysis ונתח זריקה אחת.
6. בדוק חזותית את השלד, הכדור והסל בווידאו המסומן.
7. רק אם התוצאה סבירה, תייג ונתח את יתר הסשן.

## הצלחה בפיילוט הראשון

- לפחות 40 זריקות שמורות ומקושרות ל־Baseline/Post.
- לפחות 80% מהזריקות עם Pose מספיק לניתוח או סיבת abstention ברורה.
- release ידני לכל זריקה שניתן לראות בבירור.
- דיווח coverage וגם accuracy; לעולם לא accuracy לבדו.
- רשימת כשלים לפי צילום, גוף, כדור, סל ושחרור.
