# Swisher — Basketball Vision Prototype

Swisher הוא אב־טיפוס מקומי למאמן קליעה מבוסס וידאו. המערכת מאפשרת להעלות
סרטון בודד לניתוח, או לשמור סשן רציף, לסמן בתוכו מספר זריקות ולנתח כל זריקה
בנפרד.

## הפעלה מהירה

מתיקיית הפרויקט:

```bash
source .venv/bin/activate
python -m streamlit run app.py
```

ב־Mac אפשר גם ללחוץ פעמיים על `scripts/start_swisher.command`.

## מסכי המערכת

1. **Swisher Lab** — ניתוח מהיר של קליפ זריקה יחיד.
2. **Annotation / Session Studio** — העלאת סרטון סשן רציף וסימון כל הזריקות.
3. **Session Analysis** — חיתוך וניתוח הזריקות שסומנו ושמירת התוצאות.

## תהליך הפיילוט

1. צלם סרטון רציף ב־1080p/60fps עם מצלמה יציבה.
2. פתח Session Studio וצור סשן עם מזהים אנונימיים.
3. גרור את תצוגת הפריים וסמן התחלה, שחרור וסיום לכל זריקה.
4. הוסף תוצאה ואבחנת מאמן.
5. פתח Session Analysis והתחל ב־1–3 זריקות.
6. בדוק את הסרטון המסומן ואת דוח ה־JSON לפני ניתוח הסשן כולו.

הדאטה נשמר תחת `data/sessions/<session_id>/` ואינו נכנס ל־Git.

## מה עובד

- העלאת MP4/MOV וסשנים רציפים.
- Pose estimation עם MediaPipe.
- זיהוי שחקן וכדור עם RF-DETR.
- הצעת סל עם Grounding DINO ושער ביטחון.
- מדדי מרפק, ברך, יציבות, שחרור ונחיתה.
- תיוג אמת קרקע ותיקון גרסאות.
- חיתוך אוטומטי של זריקה מתוך סשן.
- וידאו מסומן ודוח JSON לכל זריקה.
- הימנעות מהמלצה כשהראיות אינן מספיקות.

## מה עדיין דורש אימות

- זיהוי הכדור בתנועה מהירה וב־motion blur.
- זיהוי release מול פריימים שסומנו על ידי מאמן.
- make/miss על מגוון זוויות צילום.
- התאמת עצות המאמן לשחקנים אמיתיים.
- עיבוד מהיר מספיק לסשן מלא.

אין להשתמש בגרסה זו כאבחון מקצועי או רפואי. היא סביבת פיילוט לאיסוף ראיות
ולשיפור המודלים.
